# Notice

## Public disclosure and prior art

This repository publicly discloses the Harmonious framework and its associated concepts as of June 25, 2026.

Harmonious builds on and supersedes the earlier project name **Unanimous**, whose framework was publicly disclosed as of May 20, 2025. That earlier version described a consensus-building tool for collaboratively mapping and reconciling worldviews through structured exploration of values, facts, and proposed actions.

This notice is intended to help establish public documentation of the framework, process, terminology, and conceptual architecture so that the core ideas remain available for open use, critique, adaptation, and development.

## Project lineage

- **Unanimous** — earlier name and initial public white paper
- **Harmonious** — current project name and updated process framework

## Use ethos

Harmonious is shared in the spirit of good-faith inquiry, transparent facilitation, and inclusive consensus-building. The framework should not be used to manufacture false consensus, manipulate participants, or obscure unresolved disagreement.
